# Regras do Projeto

- Todo codigo-fonte deve ser comentado de forma que qualquer outra pessoa consiga compreender o que cada parte, funcao ou componente faz.
- Os comentarios tambem devem explicar as razoes e justificativas das decisoes de implementacao quando elas nao forem obvias.
- O C++ utilizado neste projeto deve ser basico, usando sintaxe simples e compativel com C++11.
- Evite recursos avancados de C++ quando uma alternativa simples em C++11 resolver o problema com clareza.
